## 🔎 نظرة عامة

يغطي النظام دورة العمل الكاملة للمعهد في تطبيق واحد: المدير يهيّئ الكورسات والقاعات والمجموعات ويدير الأموال، المدرس يتابع طلابه (حضور، درجات، مواد، ملاحظات)، والطالب يسجّل في الكورسات ويتابع جدوله ودرجاته وسجله المالي.

- واجهة عربية أصلية: RTL كامل، خط Cairo، وتصميم حديث ومتناسق.
- تغطية اختبارية: اختبارات Feature لحالات الاستخدام ولمصفوفة الصلاحيات.

## ✨ المزايا حسب الدور

### 👨‍💼 المدير
- المستخدمون: إضافة وتعديل وتعطيل حسابات الطلاب والمدرسين والموظفين.
- القاعات والكورسات: إدارة القاعات والمختبرات والكورسات (السعر، الساعات).
- المجموعات: ربط المجموعة بالكورس والمدرس والقاعة والتوقيت ومراجعة طلبات التسجيل.
- المالية: الأقساط والمدفوعات مع سند قبض قابل للطباعة، المصاريف مع سند صرف، والرواتب.
- التقارير: لوحة إحصاءات وتقرير مالي برسوم بيانية (إيرادات، مصاريف، أرباح، نسب غياب).

### 👨‍🏫 المدرس
- جدول أسبوعي لمجموعاته مع تمييز اليوم الحالي.
- رصد الحضور والغياب والتأخر.
- إدخال وتعديل وحذف الدرجات.
- رفع المواد التعليمية والواجبات لكل مجموعة.
- كتابة ملاحظات أكاديمية وسلوكية على الطلاب.

### 👨‍🎓 الطالب
- استعراض الكورسات المتاحة والتسجيل الأولي.
- متابعة الجدول الأسبوعي، سجل الحضور، الدرجات، والسجل المالي.
- تنزيل المواد التعليمية والواجبات عبر مسارات محمية.

## 🎯 الأجزاء المنجزة في المشروع (Completed Phases)

1. المخططات المعمارية والتنظيمية (Diagrams): توثيق المخططات الخاصة بالنظام (حالات الاستخدام، قاعدة البيانات، الهيكلية).
2. قواعد البيانات (Migrations): بناء الهيكل الكامل لمخطط قاعدة البيانات والجداول والعلاقات.
3. تصميم الواجهات (UI / Views): بناء وتنسيق الواجهات باستخدام Vue 3 و Tailwind CSS لدعم تجربة المستخدم باللغة العربية (RTL).

## 🚀 البدء السريع

المتطلبات الأساسية: PHP 8.2+ · Composer · Node.js 20+ · PostgreSQL / MySQL

`bash
# 1. نسخ ملف البيئة وتحديث البيانات
cp .env.example .env

# 2. تثبيت الحزم الخاصة بالخادم والواجهة
composer install
npm install

# 3. توليد مفتاح التطبيق وتنفيذ التهجيرات
php artisan key:generate
php artisan migrate --seed
php artisan storage:link

# 4. بناء ملفات الواجهة وتشغيل الخادم
npm run build
php artisan serve
